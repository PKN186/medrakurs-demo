# Медракурс — демо редизайна v4

[Открыть готовое демо](https://pkn186.github.io/medrakurs-demo/?v=4)

Адаптивная веб-концепция для презентации руководителю медицинского центра «Здравсервис Ко» в Ханты-Мансийске. Это самостоятельное предложение по редизайну.

## Что можно показать директору

- Первый экран с закреплённым заголовком «Ближе к здоровой жизни.», цветным фото центра и двумя действиями: запись и выбор направления.
- Четыре анонса с автоматическим переключением и паузой. Офтальмология взрослых и детей вынесена первой; направление подтверждено заказчиком.
- Поиск на главной по услугам, врачам и простым формулировкам: «болит спина», «капельница», «стельки», «проверка зрения». Каталог содержит 72 позиции: все 71 исходная позиция и добавленная офтальмология. 77 исходных ссылок сохранены в данных и инвентаризации.
- Прайс внутри сайта: 41 перенесённая цена с условиями, отдельная запись об уточнении стоимости офтальмологии и полный исходный документ на 15 страницах. Есть категории, поиск, переход к странице-источнику, поиск совпадений в тексте документа и скачивание PDF.
- 11 специалистов, сведения «ПроДокторов» для 9 из них со ссылками и датой проверки. Отсутствие отзывов не превращено в нулевой рейтинг.
- Демо-заявка с живым предпросмотром уведомления MAX. Выбор специалиста / услуги переносится в форму. Нет выбора времени: администратор должен перезвонить и согласовать ближайший приём.
- Версия «Аа» с крупным текстом и повышенным контрастом, мобильное меню, закреплённая кнопка записи и встроенная Яндекс.Карта с точным маркером центра.

## Демонстрационная заявка

Нажмите «Записаться на приём», выберите специалиста и нажмите «Заполнить пример». Данные сразу появляются в предпросмотре MAX. «Посмотреть заявку в MAX» открывает итоговый пример уведомления, явно помеченный как неотправленный.

Форма **не отправляет и не сохраняет** контакты, не создаёт реальную запись и очищается при закрытии. Сервер и бот MAX не подключены. CSP запрещает connect-src и нативную отправку форм. В localStorage хранится только настройка крупного текста.

На главной оставлена одна ссылка на старый сайт — в футере. Новости, каталог, цены, специалисты и информация о центре открываются внутри демо. Политика обработки данных сохранена локальным PDF из источника.

## Запуск и публикация

Без установки зависимостей и сборки:

```sh
python3 -m http.server 4178 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4178. GitHub Pages публикует main → / (root).

Шрифты Onest / Golos Text локальные, SIL Open Font License включены. Нет сторонних JavaScript-библиотек и аналитики. Карта загружается лениво; страницы прайса загружаются по одной при просмотре. Включён noindex,nofollow.

## Файлы

- index.html — главная и 7 диалогов.
- styles.css — общие токены, компоненты, адаптация и крупный текст.
- app.js — поиск, цены, анонсы, специалисты и демо-заявка.
- content.js — услуги, специалисты и объявления.
- prices.js — проверенные цены и текст страниц полного документа.
- price-list-2026-10-01.pdf, price-page-*.webp — полный прайс и страницы для просмотра.
- AGENTS.md — закреплённые решения, включая неизменяемый H1.
