# Медракурс — концепция нового сайта

Адаптивная главная страница медицинского центра в Ханты-Мансийске. Самостоятельный проект в аккаунте PKN186 рядом с `chudu-demo`.

## Смотреть

[Открыть концепцию](https://pkn186.github.io/medrakurs-demo/)

## Что сделано

- Спокойный первый экран: крупный заголовок, портрет врача и запись на приём.
- Onest для заголовков и Golos Text для основного текста; оба шрифта с кириллицей хранятся в проекте.
- Четыре основных направления на главной и отдельный каталог из 15 групп с поиском и фильтром по аудитории.
- Описание направлений и переход к записи с сохранением выбранной темы.
- Телефон, Telegram, ВКонтакте, почта и ссылка на карту.
- Мобильное меню, режим увеличенного текста и контраста, клавиатурное управление, поддержка reduced motion.

Это дизайн-концепция. Онлайн-расписание, платёжная система и отправка заявок не подключены. Запись и время приёма подтверждает администратор по телефону. Цены и сведения о врачах открываются на действующем сайте; фиктивных отзывов, стажа, наград или свободных слотов нет.

## Запуск локально

Никакие зависимости или сборка не нужны. Откройте `index.html` либо запустите из папки проекта:

```sh
python3 -m http.server 4178 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4178`. Все изображения и шрифты локальные. Внешние ссылки требуют интернет-соединения. Копирование номера работает в защищённом контексте или на localhost; при запрете доступа к буферу обмена показывается сам номер.

## Публикация

GitHub Pages → Deploy from a branch → `main` → `/ (root)`.

Включён `noindex,nofollow`: концепция не предназначена для поискового продвижения как официальный сайт центра. Перед использованием в качестве официального сайта необходимо согласовать название, айдентику, фотографию и содержание с центром.

## Проверка

Проверены основной сценарий «поиск → направление → запись», фильтр детских направлений, пустая выдача, открытие и закрытие диалогов, мобильное меню и увеличенный текст. Выполнен `node --check app.js`. Проверены ширины 320, 390 и 1280 px, включая отсутствие горизонтальной прокрутки на узком экране.
