# Медракурс — предложение по редизайну

[Открыть концепцию](https://pkn186.github.io/medrakurs-demo/)

Современная адаптивная главная для презентации медицинскому центру «Здравсервис Ко» в Ханты-Мансийске. Это самостоятельная концепция, а не официальный сайт центра.

## Что входит

- Цветное фото непосредственно с ra-kurs86.ru, более крупная типографика Onest / Golos Text и содержательно плотная композиция.
- Лента анонсов над первым экраном и блок новостей сразу под ним. Анонс Нигматулиной обозначен как пример: дата и специальность не придуманы.
- Каталог: 71 позиция в 14 разделах: сверены все 77 исходных страниц услуг, смысловые повторы объединены. Ссылки на каждую исходную страницу сохранены.
- 11 специалистов с действующего сайта; три карточки на главной и полный список в отдельном окне.
- Демо-заявка: специалист / направление, имя и телефон. Дату и время пользователь не выбирает — их должен согласовать администратор при обратном звонке.
- Пример уведомления администратору в MAX после заполнения формы. Данные **не отправляются и не сохраняются**. Закрытие формы очищает введённые контакты.
- Поиск, фильтры, мобильная навигация, закреплённая кнопка после прокрутки, режим увеличенного текста.
- Однократное появление блоков, переходы анонсов и диалогов, отклик кнопок. Поддерживается prefers-reduced-motion.

## Запуск

Без установки зависимостей и сборки:

```sh
python3 -m http.server 4178 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4178. GitHub Pages публикует main → / (root). Шрифты, фото, стили и скрипты хранятся локально.

## Демонстрация записи

Нажмите «Оставить заявку», выберите специалиста или направление и используйте «Заполнить пример». После проверки полей появится макет уведомления MAX. Он явно отмечен как неотправленный. Формирование сообщения происходит в браузере, без сетевых запросов. Политика Content Security Policy запрещает connect-src и нативную отправку форм, чтобы форма оставалась демонстрационной и при ошибке JavaScript.

Настоящая отправка в MAX не подключалась — по согласованному сценарию это презентация для клиники.

Проверка источников: 10 ноября 2026 года. Информация о ценах и расписании не дублируется и не выдумывается. Включён noindex,nofollow.
